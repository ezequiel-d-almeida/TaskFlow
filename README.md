# TaskFlow

Gerenciador de tarefas desenvolvido com TypeScript puro, sem frameworks.

## Funcionalidades

- Criar, editar e excluir tarefas
- Definir categoria e prioridade
- Filtrar por status (pendentes, concluídas, prioridade)
- Pesquisa por título, descrição, categoria ou prioridade
- Dashboard com gráfico de progresso
- Sistema de login
- Dados persistidos no localStorage

## Tecnologias

- TypeScript
- HTML5 / CSS3
- Chart.js
- Módulos ES nativos (sem bundler)

## Como rodar localmente

```bash
# Instalar dependências
npm install

# Compilar TypeScript
npx tsc

# Abrir index.html no navegador
```
